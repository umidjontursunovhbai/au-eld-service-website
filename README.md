# AU ELD Service homepage

A focused, responsive one-page website in the **Night Dispatch** direction.

## Preview

Open `index.html` directly, or run a local server from this folder:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Before launch

Replace the sample phone number, email address, and Telegram account at the top of `script.js`. Every contact link on the page reads from that single object.

The callback form intentionally opens the visitor's email application with a pre-filled message. Connect it to a real form endpoint later if submissions should happen without leaving the page.
